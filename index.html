FluxCD

Declarative continuous delivery for Kubernetes

The GitOps way to manage your infrastructure. Automate application updates and infrastructure management with Flux.

Core Pillars

account_tree

GitOps Driven

The desired state of your cluster is defined in Git. Flux ensures your cluster matches the source.

sync

Reconciliation

Continuous drift detection. If someone changes the cluster manually, Flux changes it back.

auto_mode

Automation

Automated image updates and deployment pipelines. Move from code to prod without touching kubectl.

history

Instant Rollback

Reverting a change is as simple as a Git revert. Fast, safe, and fully audited.
